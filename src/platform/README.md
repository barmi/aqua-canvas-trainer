# 브라우저 플랫폼 연동

- `storage/`: IndexedDB 트랜잭션 완료 확인, 직렬 쓰기, 400ms 자동 저장,
  백그라운드 전환 시 저장 시도, 버전이 있는 JSON 검증과 가져오기.
- `pwa/`: 프로덕션 HTTPS에서 Worker 등록, 선택한 장면 캐시 준비,
  오프라인 상태와 명시적인 업데이트 전환.

캐시 이름에 배포 경로와 콘텐츠 버전을 포함합니다. 새 Worker는 사용자가
업데이트를 누를 때까지 기다리며 이전 HTML과 해시가 있는 JS를 함께 유지합니다.
연습 저장은 캐시와 별개의 IndexedDB입니다. 영상은 모든 캐시에서 제외합니다.
캐시 쓰기 실패가 성공한 온라인 응답을 막지 않게 합니다.

알 수 없는 연습·장면 버전은 원본 레코드를 보존하고 안내합니다. 종료 직전의
비동기 쓰기는 완료를 보장할 수 없어 완료 스트로크를 평소에도 저장합니다.
중요한 연습은 JSON 파일로 백업합니다.
