# 드로잉 엔진

React에 의존하지 않는 TypeScript + Canvas 2D 모듈입니다.

| 폴더 | 책임 |
| --- | --- |
| `input/` | Pointer Events, 펜·터치, 필압·기울기, 좌표와 두 손가락 이동·확대 |
| `brush/` | 보간된 붓 스탬프, 수분·안료·농도와 시드 기반 질감 |
| `renderer/` | 누적 채색·현재 스트로크·rAF 예약·PNG 합성 |
| `history/` | 스트로크 명령과 undo/redo 분기 |

완료된 스트로크만 React 이력으로 전달합니다. 입력 중 샘플은 엔진에서 처리합니다.
선화·바탕색·가이드는 사용자 채색과 분리됩니다. 지우개는 채색에만 적용되며
PNG는 가이드와 뷰포트 변환을 제외합니다. 논리 캔버스는 1000×760입니다.
전체 재생이 가능하며 주기적인 래스터 체크포인트는 후속 최적화입니다.
