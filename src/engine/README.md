# 드로잉 엔진

React에 의존하지 않는 TypeScript 모듈로 구현할 예정입니다.

| 폴더 | 책임 |
| --- | --- |
| `input/` | Pointer Events, 펜/터치 구분, 압력·기울기 정규화, 좌표 변환 |
| `brush/` | 붓 스탬프, 수분·안료·농도, 보간, 시드 기반 질감 |
| `renderer/` | Canvas 2D 레이어 합성, 영역 마스크, 프레임 스케줄링 |
| `history/` | 스트로크 명령, 실행 취소/다시 실행, 체크포인트와 재생 |

MVP는 Canvas 2D로 시작합니다. 프레임마다 React 상태를 갱신하지 않고
입력 샘플을 버퍼에 넣어 `requestAnimationFrame`에서 렌더링합니다.
가이드 오버레이는 작품 레이어와 분리하며 내보내기에 포함하지 않습니다.
