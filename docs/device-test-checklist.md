보고했습니다. 사용자 요청으로 #7을 종료했습니다.

| 안내 항목 | 사용자 보고 |
| --- | --- |
| 펜·필압·손바닥 접촉 | 정상. 필압 차이는 있지만 작아 [#8](https://github.com/barmi/aqua-canvas-trainer/issues/8)로 개선 분리 |
| 확대·이동·화면 회전 | 정상 |
| 지우개·취소·다시 실행 | 정상 |
| 배경·시간대·광원·가이드 | 정상 |
| 저장·재접속·이어 그리기 | 정상 |
| PNG·JSON 저장·가져오기 | 정상 |
| 배치·가이드 접기·기본 사용 속도 | 정상 |

이는 사용자의 수동 확인 결과입니다. 에이전트가 직접 기기를 조작하거나
브라우저 자동화로 확인한 결과는 아닙니다. 기기 모델·OS·Pencil 모델, 정확한
테스트 빌드 및 20분 성능 수치는 제공되지 않았습니다. 직전 안내에서 HTTPS
PWA 설치·오프라인은 별도 검증으로 분리했으며 해당 결과는 보고되지 않았습니다.

아래 상세 체크리스트는 추가 검증과 재검증을 위한 서식입니다. 사용자 보고에
없는 세부 조건을 임의로 통과 처리하지 않았습니다. 필압 개선 이후의 체감은
새 버전에서 별도로 확인합니다.

## 준비

1. `npm ci`, `npm run test`, `npm run assets:verify`, `npm run build`,
   `npm run build:verify`를 통과시킵니다.
2. 펜 입력은 같은 Wi-Fi에서 `npm run dev:ipad`의 Network URL로 확인합니다.
3. 설치·오프라인은 `dist/`를 HTTPS 정적 호스팅으로 제공합니다.
   LAN HTTP와 Vite 개발 서버에서는 PWA를 검증하지 않습니다.
4. 실제 Safari로 HTTPS 주소를 열고 온라인에서 풍경을 선택한 뒤
   `오프라인 준비됨`을 기다립니다. 공유 메뉴에서 홈 화면에 추가합니다.

기기마다 표를 복사합니다. 수행하지 않은 항목은 통과로 표시하지 않습니다.

## 입력과 작업 공간

- [ ] 약한·강한 필압이 붓 크기로 구별되고 기울기 지원 기기에서 변화가 보입니다.
- [ ] 손바닥·한 손가락 접촉은 색을 남기지 않습니다.
- [ ] 펜을 누른 상태에서 손바닥·두 손가락이 닿아도 캔버스가 튀지 않습니다.
- [ ] 펜을 뗀 뒤 두 손가락 이동·확대와 다시 펜으로 칠하기가 됩니다.
- [ ] 확대 50%·100%·300%, 이동 후에도 펜 끝과 칠해지는 위치가 맞습니다.
- [ ] 캔버스 밖에서 펜을 떼거나 앱 전환 후 입력이 붙잡힌 채 남지 않습니다.
- [ ] 회전·가이드 접기·왼손 배치 변경 후 그림과 펜 좌표가 유지됩니다.
- [ ] 도구를 쉽게 누르고 패널을 스크롤해 모든 항목에 접근할 수 있습니다.
- [ ] 지우개가 채색만 지웁니다. undo/redo 후 결과가 일치합니다.

## 콘텐츠와 저장

- [ ] 6종의 선화·바탕색·마스크가 맞고 영상 장면의 연습 구도가 확인됩니다.
- [ ] 5시간대와 지원 광원을 선택하고 방향별 밝은 면·그림자 변화를 확인합니다.
- [ ] 새벽·저녁의 긴 그림자, 밤의 실내등·달빛 안내를 확인합니다.
- [ ] 5단계 이동, 힌트 숨기기와 투명도 조절이 됩니다.
- [ ] 조명을 바꿔도 이전 그림이 `나의 연습`에 남습니다.
- [ ] 완료 붓질 저장 후 Safari 재실행 시 썸네일·단계·undo 위치가 복원됩니다.
- [ ] 홈 화면 앱과 Safari에서 백그라운드 전환·재실행 후 저장을 확인합니다.
- [ ] PNG에 선화·바탕색·채색이 들어가고 힌트·화면 확대는 제외됩니다.
- [ ] JSON을 파일 앱에 저장하고 가져왔을 때 그림·조명·단계가 일치합니다.
- [ ] 잘못된 파일·버전은 기존 연습을 지우지 않고 오류를 안내합니다.
- [ ] 저장 공간 부족 시 오류 안내와 연습 파일 백업을 확인합니다.

## 설치·오프라인·업데이트

- [ ] 홈 화면 아이콘·제목·독립 화면·안전 영역을 확인합니다.
- [ ] 준비한 풍경을 비행기 모드에서 다시 열고 그리기·저장·복구가 됩니다.
- [ ] 준비하지 않은 풍경은 선택할 수 없고 이유가 표시됩니다.
- [ ] 준비한 풍경의 모든 단계·방향 힌트와 PNG 내보내기가 오프라인에서 됩니다.
- [ ] 참고 영상이 초기 로딩·필수 캐시에 포함되지 않습니다.
- [ ] 새 빌드를 올려도 연습이 끊기지 않고 업데이트 안내가 표시됩니다.
- [ ] `새 버전 사용` 후 저장한 연습이 남습니다.
- [ ] 준비 중 연결을 끊으면 안내 후 온라인 재선택으로 복구됩니다.
